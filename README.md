# 평생교육학 영어 학습 프로그램

숭실대학교 평생교육학 박사과정 면접의 영어 지문 해석을 준비하기 위한 학습 사이트입니다.

- **용어:** 평생교육 학술지에 자주 나오는 용어 293개 (영어 예문 + 한국어 해석)
- **초록 해석:** 학술지 초록 문체로 쓴 연습용 가상 초록 20편, KCI에서 가져온 실제 영문·국문 초록 붙여넣기 비교
- **내 연구:** 진학상담용 연구계획서 주제 3안 정리, 관련 이론, 가상 연습 지문, 면접 예상 질문
- **기록:** 학습량, 분류별 진도, 해석 기록 (브라우저에 저장)
